## 🌌 About Me

I design and build **ultra-low-latency financial execution engines**, **distributed in-memory key-value databases**, and **autonomous multi-agent AI research platforms**. My work sits at the intersection of high-performance C++ systems engineering, quantitative microstructure, and self-reflective agentic AI models.

- ⚡ **Core Specializations**: Low-Latency C++, Quantitative Market-Making, Distributed Systems, Multi-Agent RAG, Neural Architecture Search (NAS).
- 🚀 **Currently Building**: Low-latency crypto ETP execution platforms & reversible agent runtime substrates.
- 🎓 **Research Focus**: Multi-alpha convex signal optimization, hardware-aware KV-cache optimization, and evolutionary neural topology search.
